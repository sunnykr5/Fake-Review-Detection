Optional self-hosted fonts. ReviewGuard falls back to system fonts when these files are absent.

Download (all SIL OFL licensed) and place the WOFF2 files here:
  SourceSerif4-Variable.woff2   (display and headings)   https://fonts.google.com/specimen/Source+Serif+4
  IBMPlexSans-Regular.woff2, IBMPlexSans-Medium.woff2, IBMPlexSans-SemiBold.woff2
  IBMPlexMono-Regular.woff2, IBMPlexMono-Medium.woff2     https://fonts.google.com/specimen/IBM+Plex+Sans
Or install them system-wide: the stylesheet tries local() names first.
